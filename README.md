# シフト自動作成デモ

希望シフトのExcelをアップロードすると、条件を満たすシフト表を自動で作成します(Python / OR-Tools CP-SAT / Streamlit)。

## 動かし方

```bash
pip install -r requirements.txt
streamlit run app.py
```

画面の「サンプルデータで試す」から、飲食店(10人×30日・早番/遅番)の例をすぐ試せます。

## Excelテンプレートの書き方

| シート | 内容 |
| --- | --- |
| スタッフ | 名前 / 週の上限日数 / リーダー可(◯) |
| 希望 | 行=スタッフ、列=日付。`×`=休み希望(必ず守る)、`△`=できれば避けたい、空欄=出勤OK |
| 必要人数 | 行=日付、列=シフト名(早番・遅番など)。セルに必要人数 |

シフト名は「必要人数」シートの1行目から読み取ります。最初の列を早番、最後の列を遅番として扱います。

## 反映される条件

- 必ず守る: 必要人数、休み希望(×)、連勤上限、遅番の翌日は早番にしない、週の上限日数
- できるだけ守る(重みは画面のスライダー): △の日を避ける、勤務日数の公平性、各シフトにリーダーを配置

条件を満たせない場合は、原因の候補(出勤可能人数の不足、緩めると解ける条件など)を日本語で表示します。

## ファイル構成

```
app.py          # Streamlit 画面
solver.py       # 最適化モデル(CP-SAT)と原因診断
io_excel.py     # テンプレ読込・結果Excel出力・サンプルデータ
make_sample.py  # sample.xlsx の生成
sample.xlsx     # サンプルデータ
```
